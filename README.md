# RandomWorld

沙盒建造/生存类 2D 游戏（Unity），支持 Photon PUN 多人联机。

> 当前状态：开发中（v0.1.3），部分功能未完成。

## 项目结构

```
Assets/
├── Scenes/                  # 游戏场景 (RigisterOrLogin / Menu / Game)
├── Scripts/
│   ├── 2D/                  # 玩法代码
│   │   ├── Domain/          # 纯规则层：伤害/波次/工人/技能/成就/天气等
│   │   ├── Gameplay/        # 运行时管理器：Wave / Skill / Achievement / Session 等
│   │   ├── Character/       # 角色系统 (Player / Enemy / Worker)
│   │   ├── Map/             # 地图与 Tile 逻辑
│   │   ├── MVC/             # MVC 界面框架
│   │   ├── UI/              # HUD / 面板展示
│   │   ├── Tool/            # 无状态工具函数（18+ 工具）
│   │   ├── Data/            # 存档与同步数据
│   │   ├── Network/         # Photon PUN 网络适配层
│   │   ├── AI/              # Worker AI 系统（对话/交易/大脑）
│   │   ├── Editor/          # 自定义编辑器菜单与检查器
│   │   ├── UnityAdapter/    # Domain 接口的 Unity 实现
│   │   ├── SO/              # ScriptableObject 数据定义
│   │   └── Enum/            # 枚举 (16+ 类型)
│   └── Reference/           # 第三方库 (Photon PUN / MainThreadDispatcher)
├── Resources/               # 运行时资源
├── ResourcesLocal/          # 本地资源（不上传公开库）
├── Materials/               # 材质
├── Animation/               # 动画
├── AddressableAssetsData/   # Addressables 配置
├── StreamingAssets/         # 流式资源
└── Agent/                   # AI Agent 配置与文档
```

## 架构分层

| 层 | 说明 |
|----|------|
| **Domain** | 纯 C# 规则计算，无 Unity 依赖 |
| **Tool** | 无状态工具函数，供所有层调用 |
| **Gameplay** | 运行时管理器，连接 Domain 与 Unity |
| **UnityAdapter** | Domain 接口的 Unity 实现 |
| **UI / MVC** | 展示与交互层 |
| **Network** | Photon PUN 多人同步适配 |

### 1. 物品系统扩展

#### 1.1 新增建造物品（最常用）

**所需文件：**

| 文件 | 位置 | 说明 |
|------|------|------|
| `BuildItemData` 条目 | `Resources/SO/{Type}ItemData.asset` | Inspector 中编辑 |
| Tile 资源 | `Resources/Tilemap/Item/Build/{Name}.asset` | 瓦片资源 |
| (可选) UI 图标 | `Resources/Images/Map/{Name}.png` | 建造菜单图标 |

> 🚀 **推荐使用 `建造道具快速创建器` 工具一键完成。**
> 菜单：`工具 → 建造道具快速创建器`（`Scripts/2D/Editor/BuildItemCreatorWindow.cs`）
> 放 PNG + 切割 Sprite → 拖入贴图 → 填写参数 → 一键生成所有 Tile + DataSO 条目。

**手动操作步骤（不使用工具时）：**

1. 在 `Resources/SO/` 中找到对应类型的 `BuildItemDataSO`（如 `WallItemData.asset`）
2. 在 Inspector 的 `BuildItemDatas` 列表中添加新元素，配置字段：
   - `Name` — 英文名（必须与 Tile 文件名和图片名一致）
   - `CnName` — 中文名
   - `IsPass` — 是否可通行（`true` = 可通过，`false` = 不可通过/有碰撞体）
   - `IsNeedBuild` — 是否需要建造（`true` = 放置后半透明，等待工人建造；`false` = 立即完成）
   - `BuildCosts` — 建造材料列表（为空时默认使用 CustomWood ×5）
   - `AutoGenerateDirections` — 是否自动生成 8 方向变体（墙类物品使用）
3. 在 `Resources/Tilemap/Item/Build/` 右键 → `Create` → `2D` → `Tile`，指定 Sprite，命名为 `{Name}`
4. （可选）放置 PNG 图标到 `Resources/Images/Map/`

**`BuildItemData` 完整字段说明：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `Name` | string | 英文名，与 Tile 资源/图片名一致，作为查找 key |
| `CnName` | string | 中文显示名 |
| `Info` | string | 物品描述 |
| `IsStackable` | bool | 是否可堆叠 |
| `Type` | ItemTypeEnum | 物品类型（由 SO 的 ItemType 自动设置） |
| `IsPass` | bool | 是否可通行 |
| `IsNeedBuild` | bool | 是否需要建造流程（半透明→建造完成→不透明） |
| `BuildCosts` | List\<ResourceCost\> | 建造所需资源列表，每项指定 `ItemName` + `Count` |
| `AutoGenerateDirections` | bool | 是否为 8 方向墙类物品，自动生成 T/D/L/R/RT/RD/LT/LD 变体 |
| `EquipSlot` | EquipTypeEnum | 装备槽位（仅 Equipment 类型有效） |
| `RelatedTaskTime` | TaskTime | 搬运任务时间配置 |

#### 1.2 方向变体自动生成

开启 `AutoGenerateDirections = true` 后，一个配置条目在运行时会自动展开为 8 个变体：

| 索引 | Name 后缀 | CnName 前缀 | 方向 |
|------|------------|------------|------|
| 0 | `_0` | 左上 | LeftTop |
| 1 | `_1` | 上 | Top |
| 2 | `_2` | 右上 | RightTop |
| 3 | `_3` | 左 | Left |
| 4 | `_4` | 右 | Right |
| 5 | `_5` | 左下 | LeftDown |
| 6 | `_6` | 下 | Down |
| 7 | `_7` | 右下 | RightDown |

展开发生在 `BuildItemDataSO.GetExpandedItems()`（`Scripts/2D/SO/BuildItemDataSO.cs:50`），不修改 SO 文件本身。对于 8 个变体，需要各创建对应的 Tile 资源（`CustomRoomWall_0.asset` ~ `CustomRoomWall_7.asset`）。

**存量示例：**
- `CustomRoomWall`（墙）：8 个方向变体 → 8 个 Tile 文件
- `InventoryWall`（框）：8 个方向变体 → 8 个 Tile 文件
- `CustomDoor`（门）：不自动生成 → 1 个 Tile 文件

#### 1.3 新增背包物品

1. 在 `Resources/SO/{Type}ItemData.asset` 中添加 `ItemData` 条目
2. 在 `Resources/Tilemap/Item/Backpack/{Category}/{Name}.asset` 创建 Tile 资源
3. 在 `Resources/Images/` 对应目录下放置 UI 图标

#### 1.4 物品 ID 分配规则

物品 ID 按 `TypeInterval = 100000` 分段：

```
Id = (int)ItemType * 100000 + 序号
```

- `Weapon` 类型：ID 范围 `0 ~ 99999`
- `Equipment` 类型：ID 范围 `100000 ~ 199999`
- ...
- `Wall` 类型（值=9）：ID 范围 `900000 ~ 999999`

SO 的 `OnEnable()` / `GetExpandedItems()` 会自动分配 ID。

#### 1.5 物品类型扩展（ItemTypeEnum）

在 `Scripts/2D/Item/AItem.cs:48` 中定义所有物品类型：

- **背包类型**：`Weapon`, `Equipment`, `Consumable`, `Material`, `Task`, `Food`, `Seed`, `BackpackOther`
- **建造类型**：`Room`, `Wall`, `Furniture`, `BuildOther`
- **资源类型**：`Tree`
- **其他**：`Null`

**新增类型步骤：**
1. 在 `ItemTypeEnum` 枚举中按分组添加新值（注意保持分组连续性）
2. 在 `AItem.Ranges`（`Scripts/2D/Item/AItem.cs:15`）中更新分组范围：
   ```csharp
   { "Backpack", new ItemTypeEnum[] { ItemTypeEnum.Weapon, ItemTypeEnum.BackpackOther } },
   { "Build", new ItemTypeEnum[] { ItemTypeEnum.Room, ItemTypeEnum.BuildOther } },
   { "Resource", new ItemTypeEnum[] { ItemTypeEnum.Tree, ItemTypeEnum.Null } },
   ```
3. 创建对应的 `{NewType}ItemData.asset`（`BuildItemDataSO` 或 `ItemDataSO`）
4. SO 文件命名规则：`{EnumName}ItemData`（如 `WallItemData`、`FurnitureItemData`）
5. `ItemDataManager.Awake()` 会自动通过 Ranges 遍历加载所有 SO

#### 1.6 ABuildItem 子类化（特殊建造行为）

继承 `ABuildItem`（`Scripts/2D/Item/Build/ABuildItem.cs`）实现特殊行为：

**主要可重写成员：**
- `AddBuildTask(Vector3Int centerMap, Extra extra)` — 自定义建造逻辑
- `Width` / `Height` — 占用尺寸（默认 1×1）
- `RectType` — 锚点类型（`Center` / `BottomLeft` / `TopLeft`）
- `IsCustomSize` — 是否允许拖拽自定义尺寸
- `TileName` — 瓦片资源名

**现有子类示例（`Scripts/2D/Item/Build/`）：**
- `ARoom`（房间基类）→ `CustomRoom`（自定义房间）、`Farmland`（农田）、`Inventory`（仓库）
- `ABed`（床基类）→ `SingleBed`、`DoubleBed`

**反射发现机制**：`ItemInstanceFactory.InitItemInstances()` 自动扫描所有 `ABuildItem` 子类并实例化，无需手动注册。

**隐藏子类**：实现 `AItem.IDontShow` 接口可排除在建造菜单外。

### 7. 资源加载约定

#### 7.1 Resources 目录结构

```
Resources/
├── Tilemap/
│   ├── Map/                    # 地形 Tile（通过 TerrainTileConfig.tileResourceName 关联）
│   │   └── Resource/           # 地形上的资源 Tile（树/石头等，前缀匹配地形名）
│   └── Item/
│       ├── Build/              # 建造物品 Tile（文件名 = Name）
│       └── Backpack/           # 背包物品 Tile
│           ├── Consumable/
│           ├── Equipment/Weapon/
│           ├── Food/
│           ├── Material/
│           └── Seed/
├── SO/
│   ├── {Type}ItemData.asset    # 建造物品数据（BuildItemDataSO）
│   ├── TerrainConfigs/         # 地形配置（TerrainTileConfig）
│   ├── DropItemDataSO.asset    # 掉落数据
│   └── UIFontConfig.asset      # UI 字体配置
├── Images/                     # UI 图标
│   └── Map/                    # 建造菜单图标（文件名 = Name）
└── Prefabs/                    # 预制体
```

#### 7.2 资源加载流程

- **Tile 资源**：`ResourceManager.GetAsset(name)` → 从 `assetDic`（`Resources.LoadAll("Tilemap/")` 加载的字典）查找
- **SO 资源**：`ResourceManager.GetBuildSO(name)` / `GetBackpackSO(name)` → 从对应的 SO 字典查找
- **图片**：`ResourceManager.GetImage(name)` → 从 `imageDic` 查找
- **预制体**：`ResourceManager.Instantiate(name)` → 从 AssetBundle 加载的 `prefabDic` 查找

#### 7.3 命名约定

- SO 命名：`{ItemType}ItemData`（如 `WallItemData`、`FurnitureItemData`）
- Tile 资源名：与 `Name` 完全一致
- 资源地形 Tile：以地形 `tileResourceName` 为前缀（如 `GrassTree`、`DesertCactus`）

#### 8.1 Builder 代码生成
