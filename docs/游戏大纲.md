# RandomWorld 游戏大纲

## 一句话定位

《RandomWorld》是一款 **2D 随机地图 + 殖民地自动化 + 夜晚波次防守 + Roguelite 成长** 的生存建造游戏。

玩家在一个不断变化的随机世界中探索、采集、建造、招募工人、抵御怪物波次，并逐步把一片危险荒野经营成能够自动运转的据点。

核心体验是：

> 白天建设基地和安排工人，晚上亲自守家打怪，打赢后选择成长奖励，第二天基地变得更强。

## 游戏核心概念

游戏的重点不是单纯打怪，而是"人在前线冒险，基地在后方成长"。

玩家需要在白天规划资源、建造设施、分配工人任务；在危险来临时，亲自参战保护据点，并通过装备、技能、波次奖励和殖民地建设不断强化自己与整个基地。

- 锻炼

这套系统适合发展成半自动殖民地经营玩法。玩家负责规划，工人负责执行。

**已实现的配套系统：**

- **WorkerEfficiencyTracker**：工人效率追踪和统计
- **WorkerSupplyIssueManager**：工人资源短缺检测和告警
- **WorkerTaskCongestionAdvisor**：任务拥堵分析和建议

**v0.1.3 新增 — Worker 经济与自主 AI：**

- **ShopNPC + ShopNPCGenerator**：商店 NPC 系统，地图就绪后自动生成
- **TaskBoardManager + TaskBoardHUD**：任务板系统，Worker 存取物品的中转站
- **PlayerBountyService + BountyData**：悬赏任务系统 — Player 发布悬赏，Worker 领取执行

## 核心游戏循环

### 阶段 1：进入世界

玩家进入随机生成的世界后，首先需要寻找基础资源，建立第一个临时营地。

早期目标：

- 采集木材和石头
- 制作基础工具
- 建造篝火或殖民地中心
- 寻找食物来源
- 安置第一个工人或床位

### 阶段 2：白天经营

白天是规划和发展的阶段。

玩家主要行为：

- 探索周边地图
- 采集资源
- 建造建筑
- 种植农田
- 分配工人任务
- 整理装备和背包
- 准备夜晚防御
- 与 NPC 对话获取信息和任务（已有 AI 对话系统支持）

工人主要行为：

- 搬运资源
- 自动采集
- 修建建筑
- 种植作物
- 吃饭恢复
- 睡觉恢复
- 穿戴装备

### 阶段 3：黄昏预警

黄昏是紧张准备阶段。

系统可以提示：

- 下一波敌人数量
- 进攻方向
- 是否为 Boss 波次
- 当前天气影响
- 基地薄弱点
- 工人状态风险

玩家需要决定：

- 是否召回远处工人
- 是否优先修墙
- 是否制作药品
- 是否调整技能和装备
- 是否放弃外围建筑保核心

### 阶段 4：夜晚防守

夜晚怪物开始进攻，玩家亲自参战保护基地。

核心体验：

- 玩家负责清理高威胁敌人
- 工人或守卫辅助防御
- 建筑承担阻挡、输出或恢复作用
- 天气和地形改变战斗节奏
- Boss 波次提供强压力和高奖励

### 阶段 5：波后成长

击退波次后，玩家进入短暂休息和奖励选择。

奖励方向：

- 提升玩家攻击
- 提升玩家移速
- 降低受到伤害
- 强化技能效果
- 提升工人效率
- 增加掉落品质
- 解锁新建筑
- 强化防御设施

每次选择都会影响后续玩法，让每局游戏形成不同路线。

### 2. 把波次防守升级为基地保卫战 ✅🔧

当前已有 WaveManager 和 BossReward，可以继续扩展敌人和战场规则。

#### 敌人类型

- 普通敌人：基础近战单位
- 冲锋敌人：快速冲向建筑
- 拆墙敌人：优先攻击防御建筑
- 偷窃敌人：进入仓库偷资源
- 远程敌人：攻击工人和玩家
- 感染敌人：让工人生病或减速
- Boss 敌人：改变当前波次规则

#### 波次变化

- 多方向进攻
- 固定时间内持续刷新
- Boss 带小怪
- 特定天气强化敌人
- 敌人根据玩家基地布局选择路线

玩家每晚都要做出取舍：守住外围资源，还是收缩防线保住核心。

### 3. 强化天气与环境事件 ✅🔧

天气可以成为每天策略变化的核心。

#### 天气设计

- 晴天：工作效率正常，适合建设和远征
- 雨天：农田加速，但火把和部分陷阱失效
- 暴雪：移动变慢，需要取暖建筑
- 酸雨：腐蚀建筑，怪物发生变异
- 大雾：视野降低，稀有怪出现
- 流星夜：危险提高，但会掉落稀有矿石

天气不只是数值变化，而是改变玩家当天的优先级。

### 4. 建造系统从摆建筑升级为规划基地 ✅🔧

建筑可以从单体功能升级为互相影响的基地规划系统。

#### 建筑类别

- 生存建筑：床、篝火、厨房、仓库
- 生产建筑：工作台、熔炉、农田、磨坊
- 防御建筑：木墙、箭塔、陷阱、治疗塔
- 指挥建筑：任务告示板、警钟、殖民地中心（ColonyCommandCenter 已有基础）
- 特殊建筑：天气仪、传送门、遗迹研究台

#### 建筑联动

- 仓库靠近农田，搬运效率提升
- 厨房靠近宿舍，工人恢复速度提升
- 箭塔靠近警钟，夜晚自动锁定精英怪
- 熔炉靠近矿石仓库，生产效率提升
- 殖民地中心升级后解锁更多任务槽

这样建造不只是摆放，而是空间规划。

### 第一阶段：把核心循环做完整 ✅

## 最小可玩版本目标

一个好玩的最小版本可以只保留以下内容：

1. ✅ 玩家出生在随机地图
2. ✅ 白天采集木材、石头、食物
3. ✅ 建造床、仓库、墙和箭塔
4. ✅ 招募 1 到 3 个工人
5. ✅ 工人能自动采集、搬运、建造、吃饭和睡觉
6. ✅ 夜晚怪物从地图边缘进攻
7. ✅ 每 5 波出现 Boss
8. ✅ 击败 Boss 后选择一个强力奖励
9. ✅ 玩家死亡或殖民地中心被摧毁则失败
10. 📋 撑过指定波数后修复世界核心并胜利

> **当前进度小结（v0.1.3）**：最小可玩版本的 10 项目标中，9 项已基本实现。第 10 项（世界核心胜利条件）是衔接长期目标的关键缺口。
> 
> 项目已大幅超出 MVP 范围，进入了**玩法深度打磨和内容扩展阶段**。v0.1.3 新增了完整的 Worker 经济生态系统（货币/市场/交易/悬赏/人格/目标/大脑AI/所有权）和基础设施（商店NPC/任务板），Worker 从被动执行者升级为半自主经济个体。

## 游戏卖点总结

- 随机世界，每局地图不同
- 白天经营，夜晚防守
- 玩家亲自战斗，工人自动建设
- 天气改变策略
- Boss 波次带来强挑战
- 奖励选择形成不同流派
- 基地从小营火成长为自动化殖民地
- LLM 驱动的 NPC 对话，让世界更有生命力
- 长期目标是修复破碎世界
